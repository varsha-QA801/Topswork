Pick any one feature from a popular app you use daily (for example: Instagram signup, Flipkart add-to-cart, or Paytm recharge) and write 5 clear requirements for that feature.

Answer:
Feature: Add to Cart

User can add a product to the cart.
Cart number increases after adding a product.
Added product should appear in the cart.
User can change the quantity.
User can remove the product from the cart.

The cart should work correctly when users add, change, or remove products.

4.
Explain in 3-4 sentences the difference between forward traceability and backward traceability in the context of your table. Give one example of each using your requirements and test cases.

Answer:

Forward traceability means Requirement → Test Case.
Example: R1 (Add product) → TC1 (Check product is added).

Backward traceability means Test Case → Requirement.
Example: TC4 (Change quantity) → R4 (Change quantity).
