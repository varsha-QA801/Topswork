1.
List the 7 main phases of the Software Testing Life Cycle (STLC) and write one line describing what happens in each phase for a Login feature like the one in Instagram or Paytm.

Answer:
7 Phases of STLC – Login Feature

Requirement Analysis – Check login requirements like username and password.
Test Planning – Decide what and how to test.
Test Case Design – Create login test cases.
Test Environment Setup – Prepare the testing system.
Test Execution – Run the login test cases.
Defect Reporting – Report login bugs found during testing.
Test Closure – Check results and complete testing.
