4.
Identify 4 types of errors or issues that static testing (reviewing documents or code without execution) can catch in a test case document for an online movie booking system (like BookMyShow).

Answer:

4 Errors Static Testing 
Missing step – A step is not written.
Wrong information – Incorrect movie or seat details.
Unclear step – The step is hard to understand.
Missing result – Expected result is not given.
