Write a unit test scenario for the 'Add to Cart' function in a shopping app like Flipkart, focusing on what should be tested at the smallest code level (e.g., adding an item updates the cart count).

Answer:
Unit Test Scenario – Add to Cart
Scenario: Check the Add to Cart function.
Test: Add one product to the cart.
Input: 1 product
Expected Result: Cart count should increase by 1.

Example: If the cart has 2 items, after adding one item it should show 3 items.
