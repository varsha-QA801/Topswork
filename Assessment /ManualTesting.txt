Question 1: Based on the Agile SDLC model, explain when testing should begin in the sprint cycle,
define two entry criteria and two exit criteria you would propose for a sprint, and describe how
testing in an Agile model fundamentally differs from testing in the Waterfall model.

Answer:
In Agile, testing starts from the beginning of the sprint. Testing is done along with development.

Entry Criteria:
1. Requirements are clear.
2. The feature is ready for testing.

Exit Criteria:
1. Testing is completed.
2. Major bugs are fixed.

Agile vs Waterfall:
Agile: Testing is done during development.
Waterfall: Testing is done after development.

Agile tests early, while Waterfall tests later.
