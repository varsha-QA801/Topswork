Question 1: Based on the Agile SDLC model, explain when testing should begin in the sprint cycle,
define two entry criteria and two exit criteria you would propose for a sprint, and describe how
testing in an Agile model fundamentally differs from testing in the Waterfall model.

Answer:
In Agile, testing should start from the beginning of the sprint. Testing and coding are done together.

Entry Criteria:
1. The requirements are clear.
2. The testing setup is ready.

Exit Criteria:
1. All important tests are completed.
2. All major bugs are fixed.

Agile and Waterfall: In Agile, testing is done again and again during development. Testers and developers work together.
In Waterfall, testing is done after development is finished. So, bugs may be found late.

Question 2: Identify three non-functional testing types that are critical for this payment gateway
scenario and justify why each cannot be skipped. Then apply the relevant principle from the 7
Key Principles of Testing that explains why attempting to test every possible transaction
combination is not feasible

Answer:
1. Performance Testing:
It checks if the payment system can handle 5,000 users at one time without becoming slow or crashing.

2. Security Testing:
It checks if customer and payment details are safe from unauthorized people.

3. Reliability Testing:
It checks if the system can work properly for a long time without failing.

Testing Principle – Exhaustive Testing is Impossible:
It is not possible to test every possible transaction because there are too many combinations. So, testers should test the most important and risky cases.
