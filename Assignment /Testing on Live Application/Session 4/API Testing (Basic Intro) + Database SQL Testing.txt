4.
Suppose you have a users table in your database and the UI shows a new user 'Riya' was registered. Write an SQL SELECT query to confirm if 'Riya' exists in the users table, and explain what result you would expect if the UI and DB are in sync.

Answer:
SQL Query:

SELECT * FROM users
WHERE name = 'Riya';

Expected Result:
If the UI and database are in sync, the query should return Riya's user record from the users table.

5.
